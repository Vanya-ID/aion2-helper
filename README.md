# Aion 2 — помощник

Трекер для **Aion 2 (Global EU, асмодиане, русский клиент)**:

- таймеры ивентов по твоему времени: Портал пространства и времени, Фестиваль шиго, Межпространственное вторжение, Арена стратегии, Бездна;
- ежедневный и еженедельный чеклист, галочки сбрасываются сами;
- счётчики с расчётом, когда упрёшься в максимум (Эфирная энергия, Кошмар, Завоевание, ключи);
- пояснения для новичка по наведению на подчёркнутые слова;
- кнопки с картами metabot;
- раздел «Билды»: PvE-сборки всех классов, PvP — для Стрелка и Целителя (пассивки, активки, специализации, стигмы, статы на вещах, +уровень на вещах и арканах) и гайд по твинкам. Ссылкой на билд можно поделиться — адрес вида `…/#builds/ranger`.

## Как пользоваться

Открой сайт: **https://vanya-id.github.io/aion2-helper/** и добавь в закладки.

Устанавливать ничего не нужно, обновления подтягиваются сами (F5). Счётчики и галочки хранятся в твоём браузере.

## Плашка поверх игры (по желанию)

Маленькая программа, которая:

- показывает напоминания плашкой **поверх игры** (сколько и за сколько минут — в «Настройках» трекера);
- по **Ctrl+Alt+Q** показывает 3 ближайших ивента прямо в игре (сочетание меняется в «Настройках»);
- размер текста, ширина, высота, прозрачность и место плашки на экране тоже меняются в «Настройках».

В игру она не лезет: это просто окно поверх остальных и горячая клавиша Windows. Сайт не может сам рисовать поверх игры — браузеры это запрещают, поэтому нужна программа.

### Установка — один раз

1. На сайте нажми **«Скачать плашку»** (или возьми `aion2-helper.exe` в [Releases](https://github.com/Vanya-ID/aion2-helper/releases/latest)).
2. Запусти скачанный файл. Windows может предупредить «Система Windows защитила ваш компьютер» — у программы нет платной цифровой подписи. Нажми **«Подробнее» → «Выполнить в любом случае»**.
3. Программа сама установится, добавится в автозапуск, создаст на рабочем столе ярлык «Aion 2 трекер» и откроет сайт. Скачанный файл после этого можно удалить.
4. Браузер спросит, разрешить ли сайту доступ к устройствам в локальной сети — нажми **«Разрешить»**. Вверху страницы появится «Плашка поверх игры: подключена».
5. В игре поставь режим экрана **«окно без рамки»**: поверх полноэкранного режима никакие окна не видны.

Проверка: нажми на странице «Тест через 15 сек» и переключись в игру.

### Дальше всё с сайта

- **«Запустить плашку»** — если она не запущена (браузер один раз спросит, открыть ли приложение — поставь галочку «Всегда разрешать»).
- **«Обновить плашку»** — кнопка сама появится, когда выйдет новая версия.
- **«Выключить плашку»** — до следующего запуска.
- **Настройки → «Удалить плашку с компьютера»** — уберёт программу, автозапуск и ярлык.

## Важно

- Неофициальный фан-проект. Игровые названия и иконки принадлежат NCSOFT.
- Расписания собраны из данных клиента (metabot.gg) и проверены в игре. Где на странице написано «время не подтверждено» — ещё не проверено.

## Для разработки

Билды лежат в `builds/` HTML-фрагментами, список — в `BUILDS` / `GUIDES` в скрипте `index.html`. Общие для всех классов правила — в `builds/rules.html`, в билде на их место ставится метка `<div data-rule="passives|specs|stigmas|gear|pvp-gear|arcana"></div>`. Страница грузит файлы запросом, поэтому открытая с диска (`file://`) она билды не покажет.

`overlay.pyw` можно запускать и без сборки: `pythonw overlay.pyw --open` — тогда программа сама раздаёт страницу на `http://127.0.0.1:47123/`. Exe собирается GitHub Actions при пуше тега `vX.Y.Z`, который должен совпадать с `VERSION` в `overlay.pyw`.
